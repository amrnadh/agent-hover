# @agent-hover/overlay

The in-page UI of [Agent Hover](https://github.com/Arc-coder07/agent-hover): selector, action pill, composer, task markers, compare and undo, comments, batch, dock and sidebar. It renders in a shadow root so it never inherits or leaks styles.

Installed and injected by [`@agent-hover/vite`](https://www.npmjs.com/package/@agent-hover/vite) in dev; you do not need to install it yourself.
