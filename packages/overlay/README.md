**The in-page UI of Agent Hover.**

Selector, action pill, composer, task markers, compare and undo, comments, batch, dock and sidebar. It renders in a shadow root, so it never inherits or changes your app's styles, and it only runs in development.

It is installed and injected automatically by [`@agent-hover/vite`](https://www.npmjs.com/package/@agent-hover/vite); you don't need to install it yourself.

To set up Agent Hover in a Vite + React project:

```bash
npx agent-hover init
```
