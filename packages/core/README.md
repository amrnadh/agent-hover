**Shared engine for Agent Hover.**

Source parsing (component boundaries, props, hooks and imports), token counts, task and prompt formatting, shared types, and dev server session discovery. It is installed automatically with [`@agent-hover/vite`](https://www.npmjs.com/package/@agent-hover/vite) and [`@agent-hover/mcp`](https://www.npmjs.com/package/@agent-hover/mcp); you don't need to install it yourself.

To set up Agent Hover in a Vite + React project:

```bash
npx agent-hover init
```
