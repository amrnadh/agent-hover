# Product

<!-- impeccable:product-schema 1 -->

## Platform
web / Node.js

## Stack
TypeScript / MCP SDK

## Users
AI coding agents (Antigravity, Cursor, Claude Code, etc.)

## Product Purpose
Provides an MCP (Model Context Protocol) server so AI agents can query the visual layout of the browser, highlight components, and trigger IDE jumps programmatically.

## Positioning
Headless server exposing the Agent Hover capabilities to AI agents.

## Capabilities and Constraints
- Communicates via MCP standard.
- Headless, runs in the background.
