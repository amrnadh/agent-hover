# Place samples

Files to try **Place** with on the demo: select an element, press **P** (or drop a file on the page), and put one of these there.

- `priya-nair.png`: a photo for the testimonial's avatar, which only shows initials ("PN"). Try **Over** or **Inside start**.
- `copperleaf.svg`: a logo for the "Copperleaf" wordmark in the customer list. Try **Before**, or replace the text.
- `product-loop.webm`: a short loop for the product preview.

They live outside `public/` on purpose: Place stages the file in `.agent-hover/place/` and the agent copies it into the project.
