# Nexora (Agent Hover demo)

A small React + Vite app for developing and testing [Agent Hover](../README.md), and the fixture for the e2e suite. Nexora is a fictional product; every company name, number and quote in it is made up.

From the repository root:

```bash
npm run build   # build the packages first
npm run dev     # http://localhost:5173
```

Press Alt (or the pointer in the dock) and click anything.
