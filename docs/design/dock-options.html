One tool button

D 3 things on screen

Command bar

The dock is the status mark, the pointer and one more button (or /) that opens a search list of every action with its key. Type a few letters and press Enter.

  • + Scales to any number of features; fast for keyboard people.
  • − Every action is two steps for mouse users; nothing tells you a feature exists until you open the list.
Try: click the ⌘ button, then type “pla”.
