# Agent Hover brand

The mark is **Lift**: a solid element hovering over its own dithered shadow. One colour that follows the theme (near-white on graphite, ink on white). No other colours.

Everything in `logo/` is generated by `make-logo.mjs` (`node docs/brand/make-logo.mjs`); change the geometry there, never the files.

| File | Use |
|------|-----|
| `logo/mark.svg` | Theme-following mark (`currentColor`), large sizes |
| `logo/mark-ink.svg`, `logo/mark-light.svg` | Fixed colour, for light / dark backgrounds (README, docs) |
| `logo/mark-small*.svg` | Coarser pixels for 16–24px; the dock uses this (`packages/overlay/src/brand/mark.svg`) |
| `logo/favicon.svg`, `favicon-16/32/48.png` | Browser tab icon (the SVG switches with the OS theme) |
| `logo/apple-touch-icon.png`, `logo/icon-512.png` | App icon on a graphite tile |
| `logo/lockup-ink.png`, `logo/lockup-light.png` | Mark + wordmark |
| `logo/social.png` | 1280×640 social preview (GitHub: Settings › General › Social preview) |

Colours: ink `#111214`, light `#eeeff1`, graphite `#141518`. Wordmark: system UI font, semibold, tight tracking.

`explorations/` keeps the concepts that led here (preview pages only).
