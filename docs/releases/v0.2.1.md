Agent Hover 0.2.1 is the review release: you stay in charge of what your coding agent changes, right on the page.

## Review every change

- **A change waits on its element until you decide.** Keep it, Undo it (only the files changed since the agent started go back, file by file, never a git reset), or Follow up, and the next prompt carries what was tried before.
- **The Tasks tab is sorted by what needs you**: changes to review and failures first, then what's running, then History (folded, with Clear).
- **Nothing gets stuck.** Withdraw a task no agent has picked up yet, Send again one that timed out, Try again one that failed, or copy its prompt into any AI tool. Old history clears itself after a week.
- **Locks are checked.** If an agent changes a component you locked anyway, the marker turns amber and the card offers Undo.
- **Keys:** K Keep, U Undo, F Follow up, R Try again.

## Easier to start

- **`/agent-hover`** starts listening in Claude Code (terminal and desktop app), Cursor, OpenCode, Windsurf and Antigravity (`$agent-hover` in Codex). **`/agent-hover-status`** shows what is waiting.
- **OpenCode** is supported: `npx agent-hover init --agent opencode`.
- **`init` asks properly:** pick your agents from a checklist (the ones your project uses are ticked), see the plan per agent, confirm.
- **Connects from anywhere:** agents that run in a sandbox (Cursor, Antigravity) or from a global config (Antigravity, Windsurf, Claude Desktop) now find your dev server.
- **Settings › Agents** walks you through it: the `init` command, how to restart that agent, and its listen command.

## More precise

- **Exact file and line on React 19**, including components that don't live in a file of their own name, mapped through your dev server's source maps.
- **Plain names** on cards and lists ("Book a demo" button), and one `file:line` everywhere.
- **Pick which agent gets a task** when several are connected.

## Also new

- **Voice:** a mic in Ask and comments. It uses your browser's speech recognition, and Agent Hover never receives audio.
- **Windows** support, tested in CI.
- **Update notices** like other npm tools: a box under Vite's output with the command for your package manager and a link to these notes, plus a note on the page. Off with `NO_UPDATE_NOTIFIER=1`.
- **After an update**, if the dev server still runs the old version, the page asks you to restart it instead of failing.

## Update

```bash
npm i -D @agent-hover/vite@latest
```

(or `pnpm add -D`, `yarn add -D`, `bun add -d`), then restart your dev server and your agent. Run `npx agent-hover@latest init` to add the new `/agent-hover` and `/agent-hover-status` commands for your agents.
