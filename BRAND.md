# Agent Hover Brand Guidelines

## Core Metaphor
**Target / Locator / Precision.** 
Agent Hover is the bridge between the visual product and the underlying source code. It is a tactical tool, allowing developers to point and click to instantly jump through their architecture.

## Visual Identity
**Mode:** Dark Developer / Builder
The aesthetic is drawn from terminal windows, code editors, and high-end hardware. It avoids generic SaaS cheerfulness or generic "AI purple" slop.

### Color System
- **Primary Background:** Deep Slate / Near-Black (`#0F172A` / `rgb(15, 23, 42)`)
- **Primary Accent:** Neon Cyan / Electric Blue (`#00FFFF`)
- **Secondary Accent:** Muted Coral or subtle Lime (for warnings/success states)
- **Text:** Off-white (`#F8FAFC`) and slate (`#94A3B8`)

### Typography
- **Primary UI / Headings:** `Geist` or `Satoshi` (Sharp, clean, geometric sans-serif)
- **Monospace / Code / Data:** `JetBrains Mono` or `Geist Mono` (For coords, file paths, and metadata)
- *Strict Rule:* No `Inter`, no `Roboto`.

### Shape & Structure
- **Bento Grid:** The UI is structured into a tight vertical bento grid.
- **Squircles:** Heavy border radii (pills and squircles) create a hardware-like tactile feel.
- **Glassmorphism:** Apple Liquid Glass approximations. Multi-layered borders, deep shadows, and high blur backdrops (`backdrop-filter: blur(24px)`).

## Tone of Voice
Fast, tactical, and precise.
*Tagline Ideas:*
- "Zero friction."
- "Point. Click. Code."
- "The shortest path from pixel to source."
